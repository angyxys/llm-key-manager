Encryption Standards

  • ✓ AES-256-GCM: Industry-standard encryption for all stored keys
  • ✓ PBKDF2 (100k iterations): Master key derivation with strong hashing
  • ✓ Windows DPAPI: OS-level protection using your Windows credentials
  • ✓ 96-bit nonce: Secure random nonce for each encryption operation

Security Features

  • ✓ 2FA TOTP: Time-based one-time password authentication
  • ✓ Backup Codes: 10 recovery codes for account access
  • ✓ Auto-Lock: Configurable session timeout for unattended access
  • ✓ Audit Logging: Track all key operations and access attempts
